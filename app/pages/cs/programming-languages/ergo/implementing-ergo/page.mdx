# Implementing Ergo
This page outlines Ergo's development and implementation process. 

## Overview
Ergo is an interpreted language. It takes source code (what the user writes) and generates tokens. From there, the tokens are fed to the parser, which ultimately generates a syntax tree. That syntax tree is then fed to an interpreter, which executes the code.
