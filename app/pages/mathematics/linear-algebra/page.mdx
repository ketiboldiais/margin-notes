# Linear Algebra
These are notes I took from my courses in Linear Algebra.

## Algebras
An __algebra__ is a set of objects and a set of rules for manipulating those objects.

<Example>

Integer arithmetic is an algebra. We have a set of objects, the integers, and a set of rules for manipulating those objects:

1. ${n + 0 = n.}$
2. If ${kn = 0,}$ then ${k = 0}$ or ${n = 0.}$
3. etc.

</Example>


<Example>

Chess is an algebra. There are six types of pieces (a set of objects), and various rules for how they move on the board (a set of rules for manipulating those objects).

</Example>

__Linear algebra__ is the study of vectors and the rules for manipulating such vectors.   

## Vectors
Vectors are objects that can be added together and multiplied by scalars to produce another object of the same kind.
